# Файл в основном e-mail уведомлении

Поле «Файл для e-mail уведомления» расположено сразу под полем «Текст уведомления для e-mail». Используется стандартное файловое поле конструктора БП: можно указать файл или подставить файловое поле документа / переменную БП. Значение после вычисления выражения должно содержать ID файла CFile (либо массив таких ID). Произвольные пути и URL не принимаются.

Вложение добавляется только к основному письму всем исполнителям. Сохраняются исходное имя и MIME-тип файла. Напоминания работают по прежним правилам. Если файл удалён или недоступен, в журнал БП записывается сообщение, а уведомление отправляется без этого файла.

Для установки обновите approvecopyactiveschedule.php, properties_dialog.php и соответствующие lang/*/properties_dialog.php в установленной активити. Изменения БД и перезапуск заданий не требуются. В новых шаблонах свойство NotifyFile необязательно; в старых сохранённых экземплярах его отсутствие обрабатывается без обращения к файловому хранилищу. Уже ожидающие ответа задания не пересоздаются и повторно не уведомляются.

Проверки без установки Bitrix:

```sh
php approvecopyactiveschedule/tests/notification_attachment.php
php approvecopyactiveschedule/tests/reply_parser.php
php approvecopyactiveschedule/tests/mail_rule_adapter.php
```

Перед установкой на рабочий портал проверьте письмо с вложением на тестовом БП, подстановку файла из документа и продолжение задания, запущенного до обновления. Автономные проверки используют заглушки API Bitrix; доставку и интерфейс конструктора нужно проверить на портале.
